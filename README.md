# Horizon of My Life

人生の目標・ステップ・目標同士の影響関係を、星座とロードマップで可視化するWebアプリ（プロトタイプ）。

```bash
npm install
npm run dev
```

## 3つのビュー

| ビュー | 内容 |
| --- | --- |
| **星座（3D / 2D）** | 中心の恒星が「今の自分」。目標は惑星で、遠い軌道ほど遠い未来（年数の平方根で圧縮）、方角はカテゴリ。3Dでは惑星の大きさ＝重要度、土星のような環＝進捗、浮かぶ高さ＝進捗。影響関係は光の粒が流れる弧で表示。右上で2D表示に切り替え可能（WebGLが使えない環境では自動で2D）。 |
| **ロードマップ** | 横軸が時間（年齢つき）のガントチャート。◆がステップ、★がゴール。目標にホバーすると関係する曲線だけが光る。 |
| **ダッシュボード** | ビジョン、全体進捗、0〜90歳の人生軸と直近の目標、カテゴリ別バランス（レーダー）、次の一歩、波及効果の大きい「キーストーン目標」、前提が整っていない目標・トレードオフ。 |

## カテゴリ

星座画面の「編集」、目標の追加画面、設定から、カテゴリを自由に追加・編集・削除できる（名前・色・アイコンを選択）。カテゴリは星座の方角になり、並び順に沿って宇宙を等分して配置される。

## 影響関係の種類

- **前提**: A が B の前提条件（B の「準備度」= 前提となる目標の平均進捗）
- **相乗効果**: A が進むと B も進みやすい
- **トレードオフ**: 時間・お金などの資源を奪い合う

ステップを完了すると、その目標から影響先へ波紋が広がる演出が出ます。

## データ

- ブラウザの localStorage に自動保存（キー: `horizon-of-my-life:v1`）
- 設定（歯車）から JSON の書き出し／読み込み、サンプルに戻す、白紙から始める
- サンプルデータ: `src/data/sample.ts`

## 構成

Vite + React + TypeScript + Tailwind CSS。星座のレイアウトは d3-force（2D/3D共通、`src/lib/orbit.ts`）。3Dは three.js（React Three Fiber + drei + postprocessing のブルーム）、2Dとロードマップは手書きの SVG。3D一式は星座の3D表示を開いたときだけ遅延読み込みされる。

```
src/
  components/  各ビュー・パネル・モーダル
  lib/         store（reducer + localStorage）、analysis（進捗・波及・準備度）、date、constants
  data/        サンプルデータ
```
